### 4. CRITICAL DISCOVERY: Passivity Trap
- **Symptom**: Model converges to degenerate play — Na3 then rook shuffle (a1↔b1, g1↔h1)
- **Persists across**: all encodings, model sizes (64ch, 128ch), all hyperparameter configs
- **Black win bias**: 85-90% of adjudicated games are Black wins — persists even with symmetric encoding + fresh random start
- **Root cause**: Adjudication creates a training signal that rewards passivity
  - Adjudication says "material advantage = win" → model learns "don't lose material"
  - Safest way to not lose material = don't move meaningful pieces = rook shuffle
  - Model never learns "play actively to win" because games end before passivity is punished
  - AlphaZero avoided this by playing games to COMPLETION — passive play gets punished by checkmate
- **Evidence**: 
  - Champion v85 (promoted early, nearly random) plays better chess than v1122 (heavily trained)
  - Training literally makes the model worse
  - Value loss 0.005 looks "good" but is misleading — model predicts ~0 for all positions because nothing happens

### 5. Black Win Bias Analysis
- 85-90% Black in adjudicated games even with fresh random start
- NOT caused by encoding asymmetry (persists with symmetric encoding)
- NOT caused by color augmentation failing (augmentation is working, 50% flip)
- Likely caused by: game dynamics with low adjudication threshold + first-mover capturing patterns
- Color augmentation balances training data but can't fix the self-play game dynamics

### 6. AlphaZero/MuZero Comparison
- AlphaZero: NO adjudication, games play to completion, pure game outcome as signal
- Our Dirichlet noise (ε=0.25, α=0.3) and temperature (30 moves) match AlphaZero — exploration isn't the issue
- The TRAINING SIGNAL is the issue, not the architecture or exploration

## Proposed Next Steps (User to confirm)
1. **Remove adjudication** (or set threshold very high, e.g., 15+)
2. Let games play to completion (checkmate, stalemate, or 300-move cap)
3. Keep material-at-cap outcome for 300-move games (provides weak bootstrap signal)
4. Keep material-for-draws (provides signal for rule-based draws)
5. Accept slower early training — but avoid the passivity trap
6. The occasional checkmate provides STRONG signal that teaches "passivity = getting mated = bad"

## Session 2026-04-17 Continuation: Phase 1 Bug Fixes + 10h Baseline

### Deep Investigation (with user walkthrough)

Three compound bugs identified via careful code reading + PGN evidence analysis.
User prompt that cracked the analysis: "both sides should share the same model —
if positions are flipped, policies should mirror." PGN evidence showed strict
asymmetry (White always plays Na3 + shuffle, Black plays varied pawn advances).

### Root Cause Chain

1. **MCTS `select_child` strict-inequality tie-break** (`src/mcts/puct.rs:42`).
   With uniform-prior inputs (RandomEvaluator, early network), PUCT scores tie,
   `if score > best_score` keeps `best_idx` at the earliest index.

2. **`get_legal_moves` iteration order asymmetry** (sq 0..64 loop):
   - White's first iterable piece: b1 knight → `Nb1-a3` (passive corner move)
   - Black's first iterable piece: a7 pawn → `a7-a5` (active pawn push)
   - White's `legal_actions[0]` after `Na3` → `Ra1-b1` → closed 2-cycle forever
   - Black's `legal_actions[0]` → pawn advances → productive progression

3. **`encode_action_spatial` false promotion flag** (`encoding.rs:292`):
   `is_promo = to_rank == 7 || to_rank == 0` — flags castling + rook back-rank
   moves as "promotions," corrupting the dynamics network input for every
   castling attempt.

4. **Material shaping + adjudication creates passivity attractor** (commit 1846b78).
   `tanh(Δmaterial/5)` target gradient pulls policy toward material preservation,
   regardless of play quality.

### Combined Effect

- 85-88% Black-win rate in adjudications from game 1 (confirmed in log)
- White plays deterministic `Nb1-a3 + rook-shuffle` in every v0 PGN game
- Challenger-vs-champion eval produces ~50/50 draws (structural, not skill-based)
  → promotions rarely fire → score stalls

### Phase 1 Fix Commits (landed ee4aeaf..a09b09e)

1. `ee4aeaf` — MCTS tie-break randomization via ε=1e-6 tied-index collection + uniform pick
2. `f37f719` — `is_promo = false` for base actions (only underpromo at 4096+ is reliable)
3. `6cbe610` — remove adjudication + material-at-cap; revert to outcome=0 for caps/draws
4. `a09b09e` — opt-in Dirichlet noise via `MCTSConfig.add_root_noise`; false in eval

## Phase 2 Mid-run Intervention (2026-04-17 05:22)

### Observation

After 45 min of the first 10h run (started 04:40, killed 05:22), analysis revealed:
- **Value head dead**: value loss plateau at ~0.004, only 2 of 92 self-play games capped (outcome ~0 at cap), 89 of 92 were stalemate/repetition/50-move (outcome = 0 exactly)
- **Challenger worse than RandomEvaluator**: 0 challenger wins, 7 champion wins, 21 draws across 3 eval cycles. Win rate trajectory: 0.438 → 0.438 → 0.375 (declining)
- **Passivity resurging via policy head**: 54% of White eval games opened with `b1a3` (vs 20% expected from uniform init); challenger games showed the classic `Na3 + Ra1-Rb1 shuffle` pattern despite material-shaping being removed
- **Root cause**: policy head over-concentrates on init-bias moves because there's no value signal to correct bad priors

### Root-cause interpretation

The Phase 1 fix went TOO far in removing material signal. Removing adjudication was
necessary (it creates a passivity attractor by ending games early on material imbalance).
But also removing material-at-cap + material-for-draws starved the value head to near
zero non-zero targets. Without Q-signal, MCTS selection is purely prior-driven; the
policy head just amplifies its initialization bias.

### Intervention (commit f9012ee)

Partial revert of commit 6cbe610:
- **Kept removed**: adjudication block (the early-termination mechanism)
- **Restored**: `tanh(Δmaterial/5)` outcome for non-decisive terminals (stalemate, repetition, 50-move, 300-move cap)

Hypothesis: material-at-cap alone (without early termination) is a weaker incentive than
adjudication + material-at-cap combined. Preserving material only pays off if you survive
to a terminal — passive play still risks losing by checkmate, so the closed loop that
caused the original passivity trap should not re-form.
