### 4. CRITICAL DISCOVERY: Passivity Trap
- **Symptom**: Model converges to degenerate play — Na3 then rook shuffle (a1↔b1, g1↔h1)
- **Persists across**: all encodings, model sizes (64ch, 128ch), all hyperparameter configs
- **Black win bias**: 85-90% of adjudicated games are Black wins — persists even with symmetric encoding + fresh random start
- **Root cause**: Adjudication creates a training signal that rewards passivity
  - Adjudication says "material advantage = win" → model learns "don't lose material"
  - Safest way to not lose material = don't move meaningful pieces = rook shuffle
  - Model never learns "play actively to win" because games end before passivity is punished
  - AlphaZero avoided this by playing games to COMPLETION — passive play gets punished by checkmate
- **Evidence**: 
  - Champion v85 (promoted early, nearly random) plays better chess than v1122 (heavily trained)
  - Training literally makes the model worse
  - Value loss 0.005 looks "good" but is misleading — model predicts ~0 for all positions because nothing happens

### 5. Black Win Bias Analysis
- 85-90% Black in adjudicated games even with fresh random start
- NOT caused by encoding asymmetry (persists with symmetric encoding)
- NOT caused by color augmentation failing (augmentation is working, 50% flip)
- Likely caused by: game dynamics with low adjudication threshold + first-mover capturing patterns
- Color augmentation balances training data but can't fix the self-play game dynamics

### 6. AlphaZero/MuZero Comparison
- AlphaZero: NO adjudication, games play to completion, pure game outcome as signal
- Our Dirichlet noise (ε=0.25, α=0.3) and temperature (30 moves) match AlphaZero — exploration isn't the issue
- The TRAINING SIGNAL is the issue, not the architecture or exploration

## Proposed Next Steps (User to confirm)
1. **Remove adjudication** (or set threshold very high, e.g., 15+)
2. Let games play to completion (checkmate, stalemate, or 300-move cap)
3. Keep material-at-cap outcome for 300-move games (provides weak bootstrap signal)
4. Keep material-for-draws (provides signal for rule-based draws)
5. Accept slower early training — but avoid the passivity trap
6. The occasional checkmate provides STRONG signal that teaches "passivity = getting mated = bad"
