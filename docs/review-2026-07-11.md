# hyzero Deep Review — 2026-07-11

**Branch:** `auto/20260706-100435-iter-4`
**Date:** 2026-07-11
**Scope:** Compiled from three independent review passes — (1) Rust core, (2) Python / PyO3 bridge / scripts, (3) repo hygiene & infrastructure.

## Executive Summary

Overall health is solid: the Rust core is functionally correct (move generation, terminal detection, PUCT math, and the inference batcher shutdown path all verified clean, with 281 lib tests passing), and no secrets or missing hooks were found. However, three issues stand out as top priority: (1) a **silent uniform-policy/value-0 fallback** on any Python inference error that can flood the replay buffer with garbage targets — exactly the silent-degradation class recent commits fought; (2) **generated PGN artifacts tracked in git**, the dominant cause of an 81MB pack / 97MB `.git`; and (3) a **`.gitignore` that misses `logs/` PGNs**, letting 65+ untracked snapshots keep leaking into commits. Secondary concerns include per-node env-var reads in the hot MCTS path, a latent `transmute`-based UB in `From<u8> for Square`, leftover `/tmp` debug instrumentation, non-reproducible supervision sampling, and the absence of any CI.

## High Severity

- **Silent inference fallback floods replay buffer** — `src/py/inference_backend.rs:213-224` & `349-360`. On any Python inference error the batch silently falls back to uniform policy + value `0.0` (only an `eprintln!`, no counter/abort). A persistent shape/dtype/exception failure keeps self-play running and fills the replay buffer with garbage targets — the exact silent-degradation class recent commits (RandomEvaluator / POOL_DEAD guards) fought, but left unguarded here.

- **Generated PGN artifacts tracked in git** — `logs/eval_games.pgn` & `logs/selfplay_sample.pgn`. Both are committed and re-modified every iteration; history holds 5-6 revisions including three ~11MB blobs. This is the dominant cause of the 81MB pack / 97MB `.git`. Generated artifacts should not be versioned.

- **`.gitignore` misses `logs/` PGNs** — only `*.log` is ignored. The 65 untracked `logs/eval_games_prev_*.pgn` / `logs/selfplay_sample_prev_*.pgn` and `demos/*.pgn` are unignored and keep leaking into commits.

## Medium Severity

- **Per-node env-var reads in hot MCTS path** — `src/mcts/tree.rs:520` & `755`. `MlhBonus::from_env()` is called inside the per-node MCTS selection loop, doing 4 uncached `std::env::var` lookups (each locks the env + heap-allocates a `String`) for every node descended in every simulation, even when MLH is off. Unlike `qnorm_enabled()` / `fpu_reduction()` (OnceLock-cached), this adds lock+alloc overhead to the hottest search path; at 800 sims/move it is thousands of redundant env reads per move.

- **Latent UB in `From<u8> for Square`** — `src/lib.rs:20-22`. Guards only with `debug_assert!(s < 64)` then `mem::transmute(s)`; in a release build a value `>= 64` produces an invalid enum discriminant = UB. Public API; currently only fed 0..63 bit indices (perft / mate_solver), so latent, but any future caller with a computed/untrusted square is unsound.

- **Leftover debug probe writes to shared `/tmp`** — `python/hyzero/training/trainer.py:810-815`. Appends `[diag_reached]` to `/tmp/hyzero_diag_probe.txt` on every `train_batch` call: unbounded growth + fixed world-shared `/tmp` path (symlink/clobber, disk-fill) with no cleanup.

- **Non-reproducible, un-deduped supervision sampling** — `python/hyzero/data/pgn_ingest.py:399-404` & `tablebase.py` sample. Supervision rows are mixed into training via unseeded global `random.choices` / `random.sample` (non-reproducible) with no train/eval dedup; revives the documented demo-supervision memorization/contamination risk for any generalization claim over the corpus.

- **Branch sprawl** — 241 branches, 77 already merged into main (many `auto/*` iter branches from 2026-05/06). No pruning.

- **No CI** — no `.github/workflows` or any CI config; tests are gated only by the local `.claude/hooks/test-gate.sh`. A clone without hooks has zero automated gating.

## Low Severity

- **Per-simulation heap churn in backprop/selection** — `src/mcts/tree.rs:846-882` & `src/mcts/puct.rs:125,219`. `backpropagate` heap-allocates two `Vec`s (`rewards`, `g_values`) every simulation; `select_child` / `select_child_normalized` allocate a `tied: Vec<usize>` per node per sim. Per-simulation/per-node heap churn in the innermost loop; both could use stack / SmallVec or reuse buffers.

- **RNG re-fetched on every tie-break** — `src/mcts/puct.rs:161,270` & `tree.rs:969`. `rand::rng()` is re-fetched on every tie-break call rather than threaded through; minor, but compounds with the `tied` allocation above.

- **Coordinator ignores mid-game version / shutdown** — `src/selfplay/coordinator.rs:70`. Each game loop snapshots the model version by value at game start and never observes mid-game version changes or any shutdown signal; the only stop condition is trajectory-channel closure (no graceful drain). Intentional but worth documenting.

- **Slow test suite** — `game_task` tests (`unset_override_preserves_legacy_selfplay_window`, `true_draws_unaffected_by_rep_discount`, etc.) each run >60s, likely doing real-timing MCTS; slow CI feedback. Full `cargo test --lib` took 151s.

- **Unsafe checkpoint deserialization** — `python/hyzero/inference/server.py:162,187` & `trainer.py:1463`. Checkpoints loaded with `torch.load(..., weights_only=False)`; arbitrary-code deserialization surface if a `.pt` is ever untrusted.

- **Stale / dead `#[ignore]` tests** — `src/py/inference_backend.rs:388-453`. Two `#[ignore]` tests build `PyO3Backend::new(server, 64)` but assert `channels == 128` and `len == 128*64`; they would fail if un-ignored (stale/incorrect, effectively dead tests).

- **Stale server docstrings** — `python/hyzero/inference/server.py:66,74,119`. Docstrings say `[B,103,8,8]` / `[B,64,...]` but real `NUM_OBS_PLANES` / `input_planes` = 110 and `hidden_channels` = 128 (misleads shape debugging).

- **Hardcoded checkout path in script** — `scripts/run_passivity_batch.sh:4`. Hardcoded `cd /home/devs/workspace/hyzero` breaks on any other checkout / CI path.

- **Scripts lack `set -e`** — `scripts/run_iter_guarded.sh:54`, `scripts/run_nonstop.sh:6`. `set -u` only (no `-e`): long-running loops continue past silently-failing commands.

- **Unpinned dependencies** — `pyproject.toml` uses floors only (`torch>=2.0`, `numpy>=1.24`), no lockfile → non-reproducible env. Several Cargo deps use bare majors (`tokio="1"`, `serde="1"`, `bincode="1"`).

- **`docs/plans/` accumulation** — 34 plan dirs including completed / superseded campaigns; hard to tell active from archived.

## Verified Clean

- **Raw-pointer walks** — `unsafe { &*current }` in `tree.rs:508`/`742` are sound as-is: single-threaded per tree, shared ref dropped before the `&mut self` reborrow.

- **Secrets & hooks** — no secrets/credentials (grep hits are identifier false positives, no `.env`, no AWS-key patterns); all enforcing hooks present, executable, and wired in `.claude/settings.json`.
- **`.gitignore` positives** — correctly excludes `target/`, `checkpoints/`, `data/`, `runs/`, `settings.local.json`, worktrees.
- **Tests** — `cargo test --lib` passes (281 passed, 0 failed, 11 ignored).

## Recommended Actions

1. **[High]** Add a failure counter + abort/loud-guard to the inference fallback path (`inference_backend.rs:213-224`, `349-360`) so persistent inference errors do not silently poison the replay buffer.
2. **[High]** Stop tracking generated PGNs: remove `logs/eval_games.pgn` & `logs/selfplay_sample.pgn` from git and add `logs/*.pgn` + `demos/*.pgn` to `.gitignore`; consider history rewrite to reclaim the ~11MB blobs.
3. **[Med]** Cache `MlhBonus::from_env()` via `OnceLock` like the other env toggles (`tree.rs:520`, `755`).
4. **[Med]** Remove the `/tmp/hyzero_diag_probe.txt` debug write (`trainer.py:810-815`).
5. **[Med]** Seed the supervision sampling and add train/eval dedup (`pgn_ingest.py:399-404`).
6. **[Med]** Harden `From<u8> for Square` (`src/lib.rs:20-22`) with a checked conversion or a release-safe bounds guard.
7. **[Med]** Add a minimal CI workflow running `cargo test` / `cargo clippy`; prune the 77 merged branches.
8. **[Low]** Reduce per-sim allocations in MCTS; thread the RNG; fix stale docstrings and the two dead `#[ignore]` tests; pin dependencies; add `set -e` to loop scripts; remove the hardcoded checkout path.
