2026-04-15 — Compact: Synthesized architectural insights from MuZero training-dynamics discussion. (1) Value head dead — confirmed self-referential bootstrap: targets are MCTS root_value (untrained), initialized from and backed up through value head, so value ≈ 0 → target ≈ 0 → gradient ≈ 0 → stuck at 0 forever. Not canonical MuZero (which uses game outcome as target). (2) Reward head dead — confirmed class imbalance: only terminal steps have non-zero targets (~1% of training batches), so MSE-optimal is 0 everywhere. (3) Canonical MuZero for board games uses outcome as value target (Schrittwieser 2020 Appendix F: n=∞, γ=1). Proposed fix: soft blend β=0.1 (0.9 root_value + 0.1 outcome) to break the bootstrap loop. (4) MCTS as policy improvement requires Q to be informative; with Q ≈ 0, tree selection reduces to sampling the prior, explaining "hollow learning" (low loss, no tactical improvement). (5) Flagged unverified perspective inconsistency: game_outcome is absolute White-perspective, but network sees observation planes in absolute (not relative) space. When outcome becomes value target, must apply side-to-move sign from plane 101. Updated wiki: mcts-selfplay.md (2 new sections "Why Value/Reward Heads Dead" + expanded gotchas), neural-networks.md (2 new sections "Canonical MuZero Value Target" + "MCTS as Policy Improvement", expanded to 103 lines), mistakes.md (3 new entries: Value Dead, Reward Dead, Perspective unverified), resume.md (added perspective verification prerequisite to Experiment 2).
