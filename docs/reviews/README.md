# Reviews

This directory holds output from the scheduled bug-review routine.

Each file is one review firing. Filenames follow the pattern
`YYYY-MM-DD-<topic>.md`.

Reviews are additive: do not rewrite prior entries. If a follow-up
review revisits the same topic, create a new dated file rather than
editing the old one.

See `index.md` for the running table of commit ranges reviewed.
