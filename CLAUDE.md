## Project Overview

`hyzero` is a Rust chess engine emulating MuZero. Bitboard representation with magic bitboards for sliding pieces, async TCP server for networked play, MCTS tree search, self-play infrastructure, inference batching, and replay buffer. Python neural network layer partially implemented (Task 24 done, Tasks 25-26 pending).

## Architecture

### Rust Engine (`src/`)
- `lib.rs` — core types: Bitboard (u64), Square, Color, PieceType, Piece, PrecomputedItems
- `game/` — GameState, GameBoard (move gen, validation, pins, check/stalemate), GameHistory
- `pieces/` — magic bitboard tables for rooks/bishops, piece trait implementations
- `mcts/` — MCTSNode, MCTSTree, Evaluator trait, PUCT selection
- `selfplay/` — SelfPlayCoordinator, play_game(), InferenceBatcher, TrainingThread stub
- `data/` — board encoding (19 planes), replay buffer, K-step sampling
- `session/` — SessionObj (top-level container)
- `bin/` — server.rs, client.rs, selfplay.rs entry points

### Python Neural Network Layer (`python/`)
- `config.py` — DEFAULT_CONFIG (hidden_channels=64, num_res_blocks=4, 4096 action space)
- `models/` — RepresentationNetwork (h), DynamicsNetwork (g), PredictionNetwork (f), ResidualBlock
- `tests/test_models.py` — 9 shape/bound verification tests

## Key Dependencies

- `rand 0.9.2` — random number generation (magic bitboard search, self-play)
- `tokio 1` (full features) — async runtime for server/client/self-play
- `async-trait 0.1` — async trait methods
- `serde 1` (derive) — serialization for replay buffer
- `bincode 1` — binary serialization for replay buffer checkpoints
- `torch >=2.0` — neural network models and training (Python)
- `numpy >=1.24` — tensor interchange between Rust and Python
